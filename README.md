## Como usar

Não há build nem instalação: cada pasta é independente.

- **HTML/CSS e JavaScript:** abra o arquivo `.html` direto no navegador, ou sirva a pasta com um servidor local (por exemplo, `python -m http.server`).
- **PHP:** precisa de um servidor com PHP (XAMPP ou `php -S localhost:8000` dentro da pasta).
- **Python:** Python 3. Rode os scripts com `python arquivo.py`. Não há dependências externas nem ambiente virtual no repo.
